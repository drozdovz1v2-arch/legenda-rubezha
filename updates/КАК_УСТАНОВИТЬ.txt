  ЛЕГЕНДА РУБЕЖА — установка для игрока
═══════════════════════════════════════════

1. Распакуй ВСЮ эту папку куда угодно, например:
   C:\Games\Legenda Rubezha\

   Внутри ОБЯЗАТЕЛЬНО должны быть:
   - Launcher\LegendaRubezhaLauncher.exe   ← ЗАПУСКАЙ ЭТОТ ФАЙЛ
   - Launcher\_internal\                   ← файлы лаунчера
   - LegendaRubezha.exe
   - папка _internal\                      ← файлы игры
   - launcher_config.json
   - папка updates\

2. НЕ переноси только .exe без папок _internal!
   Не распаковывай в Downloads и не запускай из архива.

3. Запуск:
   - Дважды кликни Launcher\LegendaRubezhaLauncher.exe
   - Нажми «Играть»

4. Обновления:
   - Лаунчер сам проверит GitHub
   - Если есть новая версия — нажми «Обновить»

5. Если Windows SmartScreen ругается:
   «Подробнее» → «Выполнить в любом случае»

6. Сохранения:
   - save.json появится в корне папки игры после первой игры

Приятной игры!
